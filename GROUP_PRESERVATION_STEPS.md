# Trace and protect grouping during compression

Status: fixed protocol for the next single-boundary screen. Preserve the previous growth experiment and its sources.

The prior guided compact model learned joins but lost grouping accuracy, usually producing wrong sums with the correct group keys. Trace the frozen pre-join checkpoint against that failed compact checkpoint on new discovery prompts. Score only gold total-number prediction positions for grouping and numeric-value positions for select/rename controls. Teacher-forced evidence is separate from autonomous generation.

Sweep all 28 MLP and 28 attention modules with old-to-new activation patches, reverse patches and exact weight rollback. Use self-patching and final-residual output-copy implementation controls, with a 256 MiB CPU activation-cache ceiling and recorded CUDA peak. Rank modules by discovery grouping numeric-log-probability rollback gain minus numeric-copy gain. Freeze the top three modules and sample three disjoint random modules with matching component types. Selection is never reranked on validation or test results.

Validate on separate grouping, copying and join prompts. Measure joint rollback and first selected-module activation patching with random, shuffled-donor, reverse and zero-ablation controls. Run autonomous generation, including implementation controls that must reproduce baseline responses. A trace validates a grouping-related update contribution only if joint rollback has positive grouping numeric gain and specificity confidence bounds and improves exact grouping generation. Record failed validation explicitly; do not label it an identified circuit. Protection experiments run as predeclared even if this validation fails, as discovery-selected ablations.

Train three fresh compact learners from the original pre-join model: unconstrained compression, compression with selected-module adapters frozen, and compression with equally sized random-module adapters frozen. Reuse the previous fixed data, bounded replay, schedule, learning rates, losses and expanded teacher. Each learner has the same input tokens; the two protected arms have matching trainable parameter counts. Unconstrained capacity is larger and must be reported. Frozen modules' complete projection weights must remain bit-identical after export. This preserves local weights; upstream changes can still change the computation, so behavioral retention is measured.

Generate new development and test cohorts, excluding all prior training/evaluation prompts and discovery/validation prompts. Development includes all atomic tasks and six compositions, with 32 each plus a fixed general probe. Test has 64 per atomic task, 32 per composition and the general probe. Evaluate original, previous compressed and previous direct checkpoints as references. All compact checkpoints must save/reload in fresh processes at exactly 596,049,920 parameters with no teacher or retrieval.

Predeclared development gates: join at least 75%; each previous atomic skill and old composition within 5 percentage points of the pre-join checkpoint; fixed general MC within 5 points. Separately apply the historical-best sorting/old-skill reference so recovering an inherited deficit is distinguished from avoiding new forgetting. No final-test selection, seed search or tuning. Report grouping retention, join acquisition, compositions, query-level paired intervals and training/storage resources. A validated trace or one protected update does not establish continual learning.
